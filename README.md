# Hiragana: Tahap Eliminasi

Fakta: Sebagian besar orang yang berniat belajar bahasa Jepang menyerah di bulan pertama. Aplikasi ini hadir untuk menguji apakah Anda termasuk dalam mayoritas yang gagal tersebut.

Entah ambisi Anda adalah liburan ke Tokyo tanpa terlihat seperti turis kebingungan, membaca literatur asli, atau sekadar menonton media Jepang tanpa ketergantungan pada subtitle—semua tujuan itu omong kosong jika Anda tidak menguasai fundamental. Hiragana adalah fondasi mutlak.

Jika Anda tidak memiliki disiplin untuk menghafal karakter dasar melalui aplikasi ini, Anda tidak akan pernah menguasai bahasa Jepang. Silakan mundur sekarang.

## Inti Aplikasi
* Pendekatan brutal dan langsung untuk membaca serta mengenali karakter Hiragana.
* Tidak ada fitur kekanak-kanakan, tidak ada gamifikasi, dan tidak ada notifikasi pengingat yang menyanjung Anda. Hanya Anda dan dedikasi Anda.

## Instalasi
Unduh file `.apk` terbaru langsung dari tab **Releases** di repositori ini. 

Buktikan Anda bisa melewati tahap penyaringan paling dasar ini.
